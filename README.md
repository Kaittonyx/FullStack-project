# 🏦 Kaspi-like Banking System

Учебный/командный проект по разработке микросервисной банковской системы с поддержкой счетов, переводов, платежей и истории транзакций.

---

## 🛠 Технологический стек (Пример)
* **Backend:** Java
* **Database:** PostgreSQL
* **Frontend/UI:** HTML, CSS, JS
* **Version Control:** Git & GitHub

---

## 📋 План разработки (Roadmap)

### Этап 1: Проектирование и База Данных
- [ ] Разработать ER-диаграмму (схему базы данных)
- [ ] Спроектировать сущности: `User`, `Account`, `Card`, `Transaction`
- [ ] Настроить базовые SQL-скрипты миграции (DDL)

### Этап 2: Базовый Backend и Авторизация
- [ ] Регистрация и авторизация пользователей (JWT / Сессии)
- [ ] Создание аккаунта пользователя и привязка карт/счетов
- [ ] Реализация CRUD-операций для профиля пользователя

### Этап 3: Банковские Операции (Core Banking)
- [ ] Пополнение счета и снятие средств
- [ ] Переводы между своими счетами
- [ ] Переводы другим пользователям (по номеру телефона / ИИН)
- [ ] Проверка баланса и блокировка средств при недостатке баланса (транзакции в БД)

### Этап 4: Сервис Платежей и Истории
- [ ] Модуль оплаты услуг (коммунальные платежи, связь, штрафы)
- [ ] Генерация и просмотр истории транзакций (выписка по счету)
- [ ] Фильтрация транзакций по датам и категориям

### Этап 5: Тестирование и Безопасность
- [ ] Написание Unit-тестов для логики переводов
- [ ] Написание Integration-тестов для API
- [ ] Проверка транзакций на изоляцию (ACID) и защиту от race conditions
