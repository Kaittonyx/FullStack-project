# 🍕 Dodo-like Pizza Delivery
 
Учебный/командный проект по разработке веб-приложения доставки пиццы (по мотивам Dodo Pizza) с каталогом, корзиной, оформлением заказов и мини-игрой «Конструктор пиццы» в стиле старых браузерных игр.
 
---

## 🛠 Технологический стек
* **Frontend:** HTML, CSS, JS, Next.js (React)
* **Backend:** Next.js (API)
* **Database:** PostgreSQL
* **Version Control:** Git & GitHub

## 📋 План разработки (Roadmap)

### Этап 1: База Данных
- [ ] Создать базу данных в PostgreSQL
- [ ] Создать таблицы: пользователи, товары, ингредиенты, заказы
- [ ] Заполнить базу тестовыми данными: пиццы, напитки, закуски, ингредиенты
### Этап 2: Базовый Backend и Авторизация
- [ ] Регистрация и авторизация пользователей
- [ ] Профиль пользователя и сохранение адресов доставки
- [ ] Роли: клиент / администратор
### Этап 3: Меню, Корзина и Заказы
- [ ] Главная страница и каталог товаров по категориям
- [ ] Страница товара: выбор размера и теста
- [ ] Корзина: добавление, удаление, изменение количества, подсчёт суммы
- [ ] Оформление заказа (адрес, время, способ оплаты)
- [ ] История заказов и статусы заказа (принят / готовится / в пути / доставлен)
- [ ] Админ-панель: управление меню и заказами
### Этап 4: Мини-игра «Конструктор пиццы»
- [ ] Выбор основы, соуса, сыра и топпингов (перетаскивание на пиццу)
- [ ] Подсчёт стоимости и состава собранной пиццы в реальном времени
- [ ] Добавление собранной пиццы в корзину
- [ ] Игровые элементы: оценка пиццы, сохранение любимых рецептов
### Этап 5: Тестирование и Доработка
- [ ] Проверка работы корзины и расчёта стоимости
- [ ] Проверка оформления заказа от начала до конца
- [ ] Проверка адаптивности (телефон и компьютер)
- [ ] Исправление найденных ошибок
